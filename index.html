Privacy boundary

This prototype does not access private messages, passwords, other apps, hidden camera/microphone feeds, or an entire gallery. Media is transferred only after the owner selects files and presses the send button. The viewer cannot request hidden files.

P2P connections can fail on some networks because this prototype uses public STUN servers and no TURN server. A production version should add authentication, authorization, abuse controls, and a TURN service.
